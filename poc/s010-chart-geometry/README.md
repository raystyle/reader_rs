# s010-chart-geometry(S010 T2 PoC)

> 对应研究 `docs\research\S010-图片本体处理-提取存储与文本元数据对齐.md`。
> 验证命题:ppocr-rs polygon 盒子纯几何配对,可把带数据标签的柱状图还原成表(零新依赖)。
> 样本:安全相似系统学.pdf 图 1-1(PDF 页 13;E:\ 研究资料库,本机语料)。

## 复现

```bash
cargo run --release -- "E:/研究资料/书籍作品/安全相似系统学.pdf" 13
# 前置:reader ocr init(模型缓存);模型档 tiny
```

## 算法

盒子(polygon 四边形)取中心与 bbox;年份轴两种形态:独立 4 位年份盒,与 OCR 融合的
长数字串盒(实测年份轴融成 `20042005…2015` 单盒,按 4 位切块在盒宽内线性插值列坐标);
y 聚簇(容差 30px)取年份数最多者为轴行;数值标签(轴行上方)按 x 中心就近配列,同列
y 升序保上下序;其余文本盒列图例候选。

## 实测结论(2026-09-04,本机,tiny 档)

机制成立的部分:

- 年份轴 12 列全还原(2004 至 2015,融合串切分成功),排序正确
- 图例(事故起数/死亡人数)、轴名(年份/年)、图题(图1-1…)、页眉与正文行全部正确分离为
  文本盒(带坐标),图 1-2 的元素(下方另一图)因 y 判据正确排除在外
- 数据标签部分配对成功(83.4 / 72.8 / 62.7 / 50.6 / 41.4 / 37.9…落列)

不成立的部分(两大难点,如实记):

1. **融合数值串变长切分**:数据标签行也融合(如 `1513.7 12.711.310.19.1 8.3…` 是多个
   小数粘成单盒),小数位不定长,固定切块不可用;需按「数字流贪心切出最多合法小数」或
   逐字符盒子(det 粒度不够)。
2. **双系列列偏移**:成对柱的两组标签各偏列中心左右,纯 x 最近配列会把左系列标签吸到
   前一列(实测 83.4 落 2006 列,真值 2004);需按列内 y 众数分组或色采样。
