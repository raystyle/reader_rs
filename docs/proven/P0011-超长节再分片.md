## 背景与问题

P0010 收窄了「无标题文档」的限制，但「有标题文档的超长单节」仍不细分：一份 5000 行的单章文档照样只有一个 `section`，`--pages` 与分页对它失效。用户点名补齐。

## 目标与非目标

- 目标：
  - 有标题文档中**行数超过 200 的节**按同一预算分片为 `part` 单元；短节保持 `section` 不变。
  - 单元号保持全局连续（1 起跨 kind 递增）；kind 标单元来源（page / section / part）。
  - 无标题文档行为与 P0011 前完全一致（全 part）。
- 非目标：
  - 不做节内语义分界（保持与 PDF 页切表格同语义：part 可从任意行界切）。
  - 不做预算旗标。

## 方案

`src\anydoc.rs`：P0010 的分派泛化——`split_markdown` 产节列表后，逐节判定：`len > PART_LINE_BUDGET` 则 `chunk_lines` 产 N 个 part，否则原样一个 section。有标题走此逐节路径；无标题维持整篇 part 路径（小文档单 part 的既有行为与用例不动）。

```text
有标题: [节1(短)=section, 节2(450行)=part×3, 节3(短)=section] → 单元号 1..5
无标题: 整篇 chunk → part×N（不变）
```

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 超长节内定长切、标签 section N 续（选定）→ 即 part 方案 | 见上；节来源信息由单元顺序隐含，不单列字段 |
| 超长节标 `section N` 多次复用同号 | 单元号须唯一（过滤与 json `no` 字段依赖），弃 |
| 不切 | 用户点名，弃 |
