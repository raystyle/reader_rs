# G004-写作规范细则-禁用字符与机械判定

> 来源：用户提供《中英文 Markdown 技术文档写作规范》v1.0（2026-09-02），2026-09-03 转为本项目规则。定位：解决智能体写作痕迹（破折号、箭头、emoji、全角误用）与 lint 不可过问题；每条规则可被正则机械判定。与 G001 的关系：G001 管命名与结构（树形、标题干净、rumdl），本文件管字符与标点；冲突处以本文件为准。

## 1. 适用范围与渐进制

- 适用：全仓 markdown（根目录文件、docs 全目录），新写与改动的文档一律遵守。
- 存量已清零：2026-09-03 摸底 205 处违规（39 文件，绝大多数为 `——`），当日 swarm 清理完毕、基线文件删除；此后一律须过检。
- 门禁：`uv run --script .tools\md-char-scan.py`（退出码 0/1），列入文档门禁四件。

## 2. 豁免区

以下区域内的禁用字符合法，扫描器先掩掉再判定：

| 豁免区 | 说明 |
| --- | --- |
| 围栏代码块 | 含 mermaid 源码与公式块 |
| 行内代码 | 代码语义内容（如 `a -> b`、`port=8080`） |
| 链接与图片目标 | URL 原文 |
| 规则定义区 | 本文件的字符清单与示例（字符字面量一律放行内代码承载） |
| 第三方引文 | 报错原文、上游文档标题保持原样，置于引用块或代码块，不做规范化改写 |

## 3. P0 硬禁令

> 四类字符在豁免区外一律禁止。字符字面量见行内代码，码位供机械判定。

### 破折号与连接号

禁止：`—`（U+2014）、`——`（连用）、`–`（U+2013）、`―`（U+2015）、`−`（U+2212）、`ー`（U+30FC）。
替代：补充说明用冒号、括号或拆句；数值范围用「至」（`3 至 5 天`）或连字符（`3-5 days`）；起止页码同理。
合法：连字符 `-`（U+002D）用于复合词、CLI 参数、编号与范围。

### 箭头

禁止：U+2190 至 U+21FF 全区与装饰箭头（`→`、`⇒`、`←`、`↔`、`➜` 等）。
替代：流程步骤用有序列表；映射写「A 对应 B」；转换写「A 转换为 B」；条件分支写「若……则……」；状态迁移拆「起始状态」「目标状态」两列。
ASCII 组合 `->` 与 `=>` 仅限行内代码与代码块。

### emoji 与装饰符号

禁止：U+1F000 至 U+1FAFF、U+2600 至 U+27BF、U+2B00 至 U+2B0F、变体选择符 U+FE00 至 U+FE0F、零宽连接符 U+200D、`‼`、`⁉`、`ℹ`。
替代：提示与警告用 GFM 警示块（`> [!TIP]` 等五级）或加粗文字；状态与勾选用「是 / 否」「支持 / 不支持」文字；强调用加粗。

### 全角字符与智能引号

原则：全角仅限中文正文标点位白名单（`，。：；？！、（）《》「」『』·`，省略号用两个 U+2026 连写）。
禁止：全角字母数字（U+FF21 至 U+FF3A 等）、全角空格（U+3000）、智能引号（U+2018 至 U+201D）、全角符号混入代码、中文标点混入英文整句。
引号：中文统一直角引号「」；英文与代码用直引号。

## 4. 空格与混排

1. 中文与英文、中文与数字之间加一个半角空格。
2. 数字与单位之间加空格（`32 GB`、`100 ms`）；度与百分比不空格（`233°`、`15%`）。
3. 全角标点与相邻字符之间不加空格。
4. 不重复使用标点。
5. 链接与相邻文字之间加空格。
6. 混排句子的标点以句子主语言为准。
7. 表格内对齐只用半角空格；显示竖线转义为 `\|` 或用行内代码包裹。

## 5. 结构细则

> 与 G001 对齐的条目摘要。

- 标题：一级标题全文唯一；层级连续不跳级；句末不加标点；空标题禁止。
- 列表：同层同标记；嵌套不过三层；不以列表承载成段论述。
- 代码块：围栏必标语言，无对应语言标 `text`；示例可直接复制运行。
- 表格：表头名词短语；单元格短句。
- 链接锚文本描述目标内容；图片 alt 必填。
- 强调：加粗为最高强调；中文慎用斜体。
- 术语：专名保留官方大小写；缩写首次出现给全称；术语全文一致。

## 6. 智能体执行规则

- 高频场景对照：解释性插入语用冒号或括号；流程管道用有序列表；标题不用装饰字符；提示警告用警示块或加粗；对比表格用文字状态；代码语义内容在行内代码内保持半角。
- 输出前四步自检：回查四类禁令；确认命中均在豁免区；豁免区外命中执行替代写法；重读受影响句子确认语义无损。
