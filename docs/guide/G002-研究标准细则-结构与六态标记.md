# G002-研究标准细则-结构与六态标记

> 本细则规范 `docs\research\` 的研究、踩坑、实测文档怎么写；本文件落在 `docs\guide\`。
> 新建后须登记 `INDEX.md`。

## 一、角色定位

研究文档回答「为什么这样做、已验证什么、别再踩什么坑」，是方案与决策的事实依据。

| 文档 | 角色 |
| --- | --- |
| `TODO.md` | 当前目标任务进度 |
| `PLAN.md` | 当前目标怎么做 |
| `docs\proven\` | 已完成 plan 的归档 |
| `docs\diary\` | 项目日记（一天一篇，当天总结与自省） |
| `docs\research\` | 本规范对象：研究原型过程 |
| `docs\references\` | 开发测试参考（要做什么怎么做） |
| `INDEX.md（mistakes 节）` | 错误速查（出错怎么纠） |
| `CHANGELOG.md` / `ROADMAP.md` | 大版本 / 大阶段 |

方案落地后由 `docs\diary\YYYY-MM-DD-*.md` 记当天做了什么，研究结论留在本目录。

## 二、何时写

按需即时维护，符合任一即开一篇：

1. 踩坑当场沉淀
2. 工具或机制调研
3. 实测记录
4. 多方案对比取舍

## 三、命名

- 落点：`docs\research\`
- 文件名等于文档标题：博客式长标题，标点一律用 `-` 断句，不含空格、括号、冒号
- 一个主题一篇；写作规范（本文件）落 `docs\guide\`，不进 research 的博客式命名

## 四、结构模板

必含背景 + 关键结论。按主题取舍其它节。

```markdown
# <与文件名对齐的标题>

> 日期，来源或触发点。

## 背景
要研究什么。1 到 3 句。

## 关键结论
一屏能看完的裁决。事实性断言标六态。

## 现状或实测
版本、命令、证据。

## 踩坑沉淀
现象、根因、正确处理。

## 待办
未完成项。
```

## 五、六态标记标准

> AGENTS 写研究与测试文档规则的强约束。研究与测试文档的事实性断言（非纯描述 / 指令）须标六态之一；不标即视为未完成。标记与正文同段，用方括号。

| 标记 | 含义 | 示例 |
| --- | --- | --- |
| `[实证: ...]` | 已在本仓 / 本机实际验证 | `[实证: 2026-08-29 poc-endpoint 退出 0]` |
| `[推断: ...]` | 由现象或逻辑推出，未直接验证 | `[推断: Linux 同套 SDK 路径]` |
| `[经验: ...]` | 来自历史惯例，非本次实测 | `[经验: win-rmux 2026-08-21]` |
| `[记忆: ...]` | 记忆性陈述，建议复核 | `[记忆: 首版日期]` |
| `[假设: ...]` | 待验证的猜想 | `[假设: 升级后仍兼容]` |
| `[直觉: ...]` | 主观倾向，非依据 | `[直觉: 这样更稳]` |

用法：断言句尾加 `[实证: <依据>]`。纯描述、命令、引用行（`>`）可不标。至少关键结论处必须带标记。

禁止把「没验证」写成「已验证」（实证滥用）；禁止用猜测冒充结论。

## 六、与项目规则的衔接

- 踩坑当场落本目录，并在 `INDEX.md（mistakes 节）` 补一行
- 正文中文为主，命令 / 代码 / 专有名词保原文
- 新文档建成后，在 INDEX.md 研究节加一行

## 七、验收

写完自查：

1. 命名符合博客式长标题，落在 `docs\research\`
2. 有「背景 + 关键结论」；有踩坑则写清现象、根因、正确处理
3. 事实性断言带六态标记（至少关键结论处）
4. 已在 `INDEX.md` 登记
5. 有踩坑或成果时，`docs\diary\` 或 `TODO.md` 有钩子
6. 有可运行验证时，PoC 原型已落 `poc\` 并在 `poc\README.md` 登记

## 八、PoC 原型产物

> 研究的产物是一个 PoC 原型（D30，2026-09-03 用户裁定）。研究文档记「为什么与结论」，PoC 目录存「可复现的代码形态」，两者成对。

- 可运行验证一律落 `poc\<主题短名>\`（目录名带 S 编号前缀），约定与登记表见 `poc\README.md`
- 入仓只限源码、构建清单、辅助脚本与自述；构建产物、模型、样本大件由 `.gitignore` 钉死
- PoC 实测结论必须回填研究文档（六态标记）；poc 目录不替代研究文档
- 上游仓库实测 clone 类不搬源码入仓，只在 `poc\README.md` 登记表记指针（仓库、rev、结论所挂 S 文档）
