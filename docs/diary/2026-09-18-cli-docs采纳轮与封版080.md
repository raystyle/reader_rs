## 概貌

标准权威先读（project-evo cli-docs SKILL.md 加 references 三件：readme-standard、agent-face、templates），对照本仓 CLI 对外面逐件盘点。结论：甲面 README 四节骨架与乙面五件中四件在 REQ-057（2026-09-17，对齐总台 REQ-060）已达标，本批补两件实缺口：帮助面头行（clap 缺省无 `名@版本`，标准第三节首件）与裸调用面（旧实现 stderr 帮助加退出 2 属标准明列反例）。改动走 dev/v0.8.0：apply_help_face 递归模板全树注入 `路径@版本 描述`（版本 env! 编译期自 Cargo.toml，与 --version、--llms 同源；run() 改经 command_tree 解析，解析错误面同树同源）；裸调用改 stdout 全貌形退出 0（组子命令缺叶仍 2，用法错误不在标准辖内）。裁剪面（--filter 名、--json 顶旗标、错误双通道、CTA 字符串形、--schema 不引入等）逐件理由立 REQ-058 对照表在册，兑现 REQ-057 与 G008 挂起的细标精对齐承诺。封版 0.8.0（裸调用退出码属行为变化，R008 判据取 0.x.0）。

## 关键裁决

- 裸调用改退出 0：旧注释「保持 clap 必填子命令语义」是历史选择，标准裁定无参是导航事件非错误；旧测试 dies_no_args 随契约退役，新测试 bare_invocation_full_help_exit_zero 承载
- 帮助面模板用 mem::take 原地换（clap help_template 是消费式 builder，&mut 递归首撞 E0507）
- 七旗标不逐件改名：--filter 与 --json 名按 REQ-057 已广播契约；错误双通道改道属 major，候选不动
- 版本 0.8.0：行为变化取 0.x.0（R008 一节），非 patch
