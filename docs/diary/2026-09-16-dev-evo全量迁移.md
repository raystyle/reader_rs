## 自省

- 编号连续性是存量迁移的第一对账面：D 号即 REQ 号让 47 条历史需求与新队列零翻译互通，比重新起号（REQ-001 起）多付的成本只是三位数的空号段，换来 PRD 档案与 REQ 索引可以互相直查。
- 迁移不是搬运是重审在标题括号上应验：旧体系自己的门禁（md-heading-scan）报红九处无人清偿，新门禁（PE-10）一接就逼出 docs 面五处；门禁叠加的意义正是让债无处存身，但清偿要限定在检查面内（PLAN 与 ROADMAP 与 poc 留档不动），不为凑绿改写历史。
- 楷模仓对表省了三个坑：MD025 frontmatter title 配置、归档件单 h1（迁移注记走标题后引用行而非另立标题）、REQ 文件名与标题避括号（本仓扫描连全角括号一起查，比 dev-evo 的 PE-05 更严）。
