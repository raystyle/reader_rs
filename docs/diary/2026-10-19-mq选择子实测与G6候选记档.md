# 2026-10-19 mq选择子实测与G6候选记档

> 来源：office-mesh 房 w1E 问询 query 的 mq selector 语义文档（reader v0.11.0 面）；应答前本机实测钉语义，顺带发现文档例误导件一件。

## 实测语义面

靶件现造 markdown 加本仓 README，v0.11.0 本机实弹：

- 标题：`.h1` 至 `.h6` 各级，`.h` 任意级，`.h(1, 2)` 与 `.h(1..3)` 级别选与范围
- 代码块：`.code`，`.code("rust")` 按语言过滤，`.code.lang` 取语言名
- 链接：`.link` 整体，`.link.url` 取 URL
- 表格：`.table` 与 `.[][]` 单元格，`.[][] | select(contains("甲"))` 单元格过滤
- 文本：`.text` 节点文本值
- 块级 grep 惯用式：`select(contains("关键词"))` 直取（命中段落节与列表项等块），`.text | select(contains("关键词"))` 行文本过滤
- json 形态 `data` 为 `results[]` 加 `count`，`--filter 'results[]'`；退出码命中 0 无命中 1 出错 2；不吃目录，图片无文本层不支持

## 坑两件

1. `.[]` 语义窄：实为子节点迭代，根上只出列表项（实测 `.[] | select(contains("配置"))` 对本仓 README rc=1，README 无含该词的列表项）。通用块过滤不需要 `.[]` 前缀，`select(contains(...))` 直取即对。
2. 上游 CLI 内建族不可用：mq CLI 的 `section::section(...)` 与 `csv::` 等内建在 reader 内嵌 mq-lang 引擎 rc=2（报 `"section" is not defined`）；mqlang.org 文档描述 CLI 面，语义以 reader 实测为准。

## 记档 G6 候选

README:268 行文与 README:272 例、src/lib.rs:198 help 例三处同用 `.[] | select(contains("..."))` 作「管道组合」示范例，语义实窄（坑一），对本仓自身 README 跑即 rc=1，示范误导。修向：改 `select(contains("..."))` 直取式；涉 README 两处加 help 例一处，`--llms` curated 例为 `.h2` 不受累故快照不动；宜独立小批。本批只记不改。

## 增记 .table 表形问答与坑二更正

> 来源：office-mesh 房 w1E 追问 query text 形态下 `.table` 逐格一行的渲染归属；深挖后更正本档坑二。

`.table` 表形归属（实测加源码核）：text 形态按每个命中值渲染是既定契约；管道表形不回来的根因在上游 mq-markdown 文档模型，无 Table 与 TableRow 保形节点，mdast 表在解析期摊平为 TableCell（带 `.row` / `.column` 坐标）加 TableAlign（输出里那行 `|---|---|` 即其渲染）；TableRow 的管道形渲染臂存在但解析道不产 TableRow 节点，故 `.table` 整表管道输出当前不可达。表格形的实用道：`import "table" | nodes | table::tables(self)` 出结构（header 与 rows 与 align 数组），续 `| table::to_csv(first(self))` 出 CSV 行形（实测出 列1,列2 与 甲,乙 两行）；`table::to_markdown` 拼回的仍是散格节点序列。

坑二更正（更正本档上方坑二）：mq-lang 模块库在内嵌引擎经显式 import 可用，此前断言不可用属实测不完整。`import "<mod>" |` 形态实测过 table 与 section，modules 目录在册十四件（table、section、csv、json、yaml、toml、xml、html、semver、fuzzy、gron、toon、cbor、md）；裸 `section::` 形态才不可用（命名空间不自动引入，属 mq CLI 的 `-A` 便利）。另一关键段形态是 `nodes` 聚合段（把逐节点输入聚成数组，module 函数要全量节点时的内嵌等价物；`import "section" | nodes | section::section("标题")` 实测干净过，无 stderr 噪音）。坑一的 `.[]` 语义与 G6 候选不变。
