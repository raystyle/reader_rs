# M101-文档门禁扫描错误

> 错误速查分类文件：rumdl / md-ref-scan / md-heading-scan 相关踩坑。行级编号 M0xx 全局递增不复用；迭代规则见 `INDEX.md` 八、错误速查。

## M001 URL 内嵌 docs 路径被断链扫描误判

- 日期：2026-08-31
- 现象：`md-ref-scan.py` 把 markdown 里的外链 URL（如 `https://github.com/firecrawl/pdf-inspector/blob/main/docs/rust-api.md`）中内嵌的 `docs/rust-api.md` 片段当仓内引用，报断链。
- 根因：扫描器按文本模式提取 `docs` 前缀路径，不区分 URL 与仓内相对引用。
- 正确处理：外部仓文档引用保留 URL 原形（不要把链接改写成裸路径规避扫描），同时在 `.tools\md-ref-allow.txt` 的「外部仓内路径」节为 `docs/rust-api.md` 这类路径加锚定豁免正则（`.` 需转义，写法见该文件）。本仓首开此节即此例。
