# M101-文档门禁扫描错误

> 错误速查分类文件：rumdl / md-ref-scan / md-heading-scan 相关踩坑。行级编号 M0xx 全局递增不复用；迭代规则见 `INDEX.md` 八、错误速查。

## M001 URL 与散文中的 docs 前缀路径被断链扫描误判

- 日期：2026-08-31
- 现象：`md-ref-scan.py` 把 markdown 里非仓内引用的路径形态报断链。两例同根因：外链 URL 内嵌片段（如 `https://github.com/firecrawl/pdf-inspector/blob/main/docs/rust-api.md` 中的 `docs/rust-api.md`）；散文里的示意形态（如「docs 前缀加文件名」若写成 `docs\` 紧跟点号与 md 的示意串也会命中）。
- 根因：扫描器按文本模式提取 `docs` 前缀路径，不区分 URL、散文示意与仓内相对引用。
- 正确处理：真实的外部仓文档引用保留 URL 原形，在 `.tools\md-ref-allow.txt` 的「外部仓内路径」节为 `docs/rust-api.md` 这类路径加锚定豁免正则（`.` 需转义，写法见该文件）；散文示意则改写成不构成路径形态的措辞（如「`docs\` 前缀加文件名」），不为一笔带过的示意加豁免。本仓首开豁免节即此例。

## M006 门禁命令管道接 tail 吞非零退出码

- 日期：2026-09-01
- 现象：md-heading-scan 两次报出括号标题，但 `... && uv run --script .tools\md-heading-scan.py | tail -1 && git add ...` 链条照样继续提交推送；同日 `gh run watch | tail` 也吞过失败码。工具本身正确返回 1。
- 根因：shell 管道退出码取末位命令（tail 恒 0），门禁的非零码被吞；`&&` 链因此永不阻断。
- 正确处理：门禁与盯守命令在 gated 链里**裸跑不接管道**（要看短输出先跑门禁、再单独取日志）；或显式 `set -o pipefail`。工具不背锅，改用法。
