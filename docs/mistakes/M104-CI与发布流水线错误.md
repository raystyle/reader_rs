## M004 macos-13 Intel runner 已退役，release job 永久排队

- 日期：2026-08-31
- 现象：release run 33457730048 四 job 中 `x86_64-apple-darwin`（runs-on: macos-13）排队 25 分钟以上不调度，其余三 job 早已完成。
- 根因：GitHub 已退役 macos-13 Intel runner（无可用容量），job 永远等不到执行器。
- 正确处理：Intel mac 二进制改在 macos-latest（ARM）上交叉编译——rust-toolchain action 的 `targets:` 加 `x86_64-apple-darwin`，同一 Xcode SDK 支持双架构。通用教训：CI 矩阵选 runner 标签前先确认该标签仍在 GitHub 支持列表；退役 runner 的症状是 job 永久 queued 而非报错。
