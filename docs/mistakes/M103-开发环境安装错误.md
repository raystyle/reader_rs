## M003 rumdl 装成 x86_64 二进制在 arm64 mac 上无法运行

- 日期：2026-08-31
- 现象：mac 接管验收跑 `rumdl check .` 报 `bad CPU type in executable`；`file` 查看二进制为 `Mach-O 64-bit executable x86_64`，而主机 `uname -m` 为 `arm64`。
- 根因：接管装工具时下载了 x86_64-apple-darwin 资产，Apple Silicon 主机且未装 Rosetta 2，无法执行异架构二进制。
- 正确处理：按主机架构选发行资产（arm64 mac 对应 aarch64-apple-darwin，见 rvben/rumdl releases）；装完先 `file` 加 `--version` 冒烟再进门禁。通用教训：换机接管时装的工具二进制先验架构与可执行性，再跑门禁。
