# ADR-0004:模型与升级自维护镜像三级回退

## Context

v0.4.0 封版验收暴露模型 HuggingFace 直连国内机器首用不可达（lan-linux 三连重试失败）；self update 原走 GitHub API 亦有配额与可达性问题。裁定与基建回执见 GitHub ISSUE #1；OCR 落地决策见 ADR-0003，版本成果见 CHANGELOG v0.5.0（原 P0014 方案档案已清退，ADR-0006）。

## Decision

模型下载与 self update 默认走自有镜像 `reader.ohmygh.com`（R2 自定义域，ohmycloud 承载）：模型三级回退（镜像 到 HF 直连 到 GitHub Releases models-v6 tag 恒 prerelease）；self update 先读镜像 `reader/latest.json` 不可用回退 GitHub API；`ocr init / doctor / switch` 三子命令管模型；镜像件 sha256 与官方边车一致，CI 镜像腿幂等（无变化零下载零上传）。

## Consequences

- 好：国内机器首用不卡 HF；`READER_MIRROR` 可覆盖基址；内网机器可整目录拷缓存加 `--offline` 手动部署
- 坏：自维护分发多一条 CI 腿（mirror job 加 mirror-models.yml 周更）与 pin 表维护义务；镜像不可达依赖回退链测试（tests/mirror.rs 直测）
- 旧 GOAL 挂账「等 ISSUE #1 大陆侧第三级回退演练回执后归档」已销：REQ-050 五端 ark 回执（镜像通道 install/update、三态齐、doctor 零红）实质覆盖 [实证: REQ-050 trace]；镜像分发实现细则（models-v6 恒 prerelease、doctor 只读、switch 锚兄弟位等九项）代码即真相，以 `src/mirror.rs` 注释与两个 workflow 为准
